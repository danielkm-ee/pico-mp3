# A small mp3 player based on the RP2040-Zero and MAX98357A
This is a small pet-project that I put together to help my project group for a science inquiry class.

Their research project involved playing tones for grass seeds to see if there is any effect on the growing process; these devices are used to affordably play music from an MP3 file on a loop with little maintenence requirements.

# Dependencies
This project utilizes the following libraries (automatically handled via CMake):
* **Pico SDK** (v2.3.1)
* **pico_audio_i2s** (from pico-extras)
